# i18n (sr/en/de) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cijela aplikacija (UI, emailovi, izvozi, AI asistent, URL putanje) na sr/en/de, jezik fiksiran per-deployment kroz `NEXT_PUBLIC_APP_LOCALE`.

**Architecture:** next-intl **bez i18n routinga** — jedan locale iz env-a učitan kroz `i18n/request.ts`; katalozi `messages/{sr,en,de}.json` sa namespace-ovima po domenu; prevodive URL putanje preko centralne route mape koja generiše rewrites/redirects u `next.config.ts` + `href()` helper. Spec: `docs/superpowers/specs/2026-07-05-i18n-design.md`.

**Tech Stack:** Next.js 16 (App Router, webpack build), next-intl v4, TypeScript, vitest, Playwright.

## Global Constraints

- Grana: `feat/i18n`. Radi se na njoj, commit poslije svakog taska.
- `NEXT_PUBLIC_APP_LOCALE` = `sr` | `en` | `de`; default **`sr`** — postojeći TEHPRO deployment mora raditi bez ijedne env promjene.
- Srpski tekstovi idu u `messages/sr.json` **1:1, verbatim** (ijekavica ostaje). Ništa se ne "popravlja" usput.
- Sadržaj iz baze (vrste provjera, lokacije, bilješke, nazivi firmi...) se NE prevodi.
- Postojeći unit i e2e testovi moraju prolaziti nepromijenjeni pod default `sr` (assertion-i na srpske tekstove se NE mijenjaju).
- Poslije svakog taska: `npm run typecheck && npm run test:unit` mora proći.
- Ključevi kataloga: `camelCase`, ugniježdeni po komponenti/ekranu, npr. `klijenti.noviKlijent.naslov`. Interpolacija next-intl sintaksom: `"pozdrav": "Zdravo {ime}"`. Pluralizacija ICU sintaksom: `"dana": "{count, plural, one {# dan} other {# dana}}"`.
- U svim taskovima važi **Procedura ekstrakcije stringova** (odmah ispod).

## Procedura ekstrakcije stringova (važi za sve UI taskove)

Za svaki fajl iz task-liste: pronađi SVE korisniku vidljive stringove — JSX tekst, `placeholder`, `title`, `aria-label`, `alt`, toast poruke, poruke grešaka iz server akcija, Zod poruke, `confirm()` tekstove, labele dugmadi. Identifikatori, ključevi, className, rute i vrijednosti koje idu u bazu se NE diraju.

**Pattern A — server komponenta (async, bez "use client"):**

```tsx
import { getTranslations } from "next-intl/server"

export default async function Page() {
  const t = await getTranslations("klijenti")
  return <h1>{t("naslov")}</h1>
}
```

**Pattern B — client komponenta ("use client"):**

```tsx
"use client"
import { useTranslations } from "next-intl"

export function NoviKlijentButton() {
  const t = useTranslations("klijenti.noviKlijent")
  return <button>{t("dugme")}</button>
}
```

Namespace client komponente MORA biti u `CLIENT_NAMESPACES` (`i18n/client-namespaces.ts`) — inače `useTranslations` baca grešku u runtime-u. Provjeri pri svakom dodavanju.

**Pattern C — ne-React kod (server akcije, lib/, skripte, API rute):**

```ts
import { createTranslator } from "next-intl"
import { APP_LOCALE } from "@/lib/locale"
import { getMessages } from "@/i18n/messages"

const t = createTranslator({ locale: APP_LOCALE, messages: getMessages(), namespace: "email" })
t("podsjetnik.naslov", { firma: "Maglić Metal" })
```

**Konstante na module-nivou** (npr. `NAV_ITEMS` sa `label`): zamijeni `label: "Pregled"` sa `labelKey: "pregled"` i prevedi na mjestu renderovanja (`t(item.labelKey)`).

**Za svaki task:** dodaj ključeve u sva TRI kataloga u istom commitu (sr verbatim, en i de prevedi; de prevod mora koristiti standardnu poslovnu terminologiju — Kunde, Termin, Begehung, Protokoll, Bericht, Einstellungen). Na kraju taska pokreni dijakritički sweep nad fajlovima taska:

```bash
grep -rn "[šđčćžŠĐČĆŽ]" <fajlovi-taska> | grep -v "\.test\." || echo "ČISTO"
```

Preostali pogoci smiju biti samo komentari u kodu (komentari se ne prevode).

- [ ] **Step 4: Implementiraj lib/locale.ts**

```ts
// Jezik aplikacije — fiksiran per-deployment, bira ga isključivo developer.
// Mijenja se ISKLJUČIVO preko env varijable (zahtijeva rebuild):
//   NEXT_PUBLIC_APP_LOCALE — "sr" | "en" | "de"; default "sr".
// Isti pattern kao lib/brand.ts.

export const SUPPORTED_LOCALES = ["sr", "en", "de"] as const
export type Locale = (typeof SUPPORTED_LOCALES)[number]

export function parseLocale(raw: string | undefined): Locale {
  const v = raw?.trim().toLowerCase()
  if (v && (SUPPORTED_LOCALES as readonly string[]).includes(v)) return v as Locale
  if (v) console.warn(`[locale] Nepoznat NEXT_PUBLIC_APP_LOCALE="${raw}" — fallback na "sr".`)
  return "sr"
}

export const APP_LOCALE: Locale = parseLocale(process.env.NEXT_PUBLIC_APP_LOCALE)
```

- [ ] **Step 2: Implementiraj `i18n/routes.ts`**

```ts
import { APP_LOCALE, type Locale } from "@/lib/locale"

// Fizičke (srpske) putanje → prevodi. Segment koji nije u mapi ostaje isti.
export const ROUTE_MAP: Record<string, { en: string; de: string }> = {
  "klijenti": { en: "clients", de: "kunden" },
  "termini": { en: "appointments", de: "termine" },
  "obilasci": { en: "visits", de: "begehungen" },
  "plan-aktivnosti": { en: "activity-plan", de: "aktivitaetsplan" },
  "zapisnici": { en: "records", de: "protokolle" },
  "dokumenti": { en: "documents", de: "dokumente" },
  "pregled": { en: "overview", de: "uebersicht" },
  "prikaz": { en: "view", de: "ansicht" },
  "postavke": { en: "settings", de: "einstellungen" },
  "prijava": { en: "login", de: "anmeldung" },
  "zaboravljena-lozinka": { en: "forgotten-password", de: "passwort-vergessen" },
  "nova-lozinka": { en: "new-password", de: "neues-passwort" },
  "odjava": { en: "logout", de: "abmeldung" },
}

export function localizeHref(path: string, locale: Locale = APP_LOCALE): string {
  if (locale === "sr") return path
  const [pathname, query] = path.split("?")
  const segs = pathname.split("/").map((s) => ROUTE_MAP[s]?.[locale] ?? s)
  return segs.join("/") + (query ? `?${query}` : "")
}

export const href = (path: string) => localizeHref(path)
```

- [ ] **Step 3:** `npx vitest run i18n/routes.test.ts` → PASS.

- [ ] **Step 4: rewrites + redirects u `next.config.ts`**

```ts
import { ROUTE_MAP } from "./i18n/routes"
import { parseLocale } from "./lib/locale"

const locale = parseLocale(process.env.NEXT_PUBLIC_APP_LOCALE)

const nextConfig: NextConfig = {
  experimental: { serverActions: { bodySizeLimit: "12mb" } },
  async rewrites() {
    if (locale === "sr") return []
    return Object.entries(ROUTE_MAP).map(([sr, tr]) => ({
      source: `/${tr[locale]}/:path*`,
      destination: `/${sr}/:path*`,
    }))
  },
  async redirects() {
    if (locale === "sr") return []
    return Object.entries(ROUTE_MAP)
      .filter(([sr, tr]) => sr !== tr[locale])
      .map(([sr, tr]) => ({
        source: `/${sr}/:path*`,
        destination: `/${tr[locale]}/:path*`,
        permanent: true, // 308
      }))
  },
}
```

Napomena: `i18n/routes.ts` se importuje u next.config — ne smije vući React ni ništa van `lib/locale.ts`. Rewrites bez `:path*` varijante dodaj i za goli segment (`/clients` → `/klijenti`): koristi dva pravila po ruti ili `{ source: "/clients{/:path}*" }` — provjeri na dev build-u koji oblik Next 16 prihvata i primijeni.
